# Синтаксис и ядро языка N&S

Данный документ содержит полное описание синтаксиса, грамматики, системы типов данных и правил выполнения выражений в языке **N&S (Nova Script)**.

---

## 1. Лексическая структура

### 1.1. Идентификаторы
Идентификаторы используются для именования переменных, функций и модулей.
* Имя идентификатора должно начинаться с латинской буквы (`a-z`, `A-Z`) или символа подчёркивания `_`.
* Последующие символы могут включать латинские буквы, цифры `0-9` и символ подчёркивания `_`.
* Регистр символов имеет значение (`myVar` и `myvar` — две разные переменные).

```javascript
let count = 10;
let _temp_value = 20.5;
let userName = "Alice";
```

### 1.2. Литералы
* **Целые числа (Int):** последовательность десятичных цифр (`0`, `42`, `-100`).
* **Числа с плавающей точкой (Float):** последовательность цифр с точкой (`3.14`, `0.5`, `-12.0`).
* **Строки (String):** последовательность символов в двойных `"` или одинарных `'` кавычках. Поддерживаются экранированные символы: `\n`, `\t`, `\r`, `\\`, `\"`, `\'`.
* **Булевы значения:** литералы `true` и `false`.
* **Пустое значение:** литерал `null`.

### 1.3. Комментарии
Язык поддерживает два вида комментариев:
* **Однострочные комментарии:** начинаются с `//` и продолжаются до конца текущей строки.
* **Многострочные (блочные) комментарии:** обрамляются символами `/*` и `*/`.

```javascript
// Это однострочный комментарий

/*
   Это многострочный блочный комментарий.
   Он может занимать произвольное количество строк.
*/
let speed = 60; // комментарий в конце строки
```

### 1.4. Разделители и точки с запятой
Инструкции в языке N&S разделяются точкой с запятой `;`. Точка с запятой является обязательным разделителем инструкций `let`, `return`, вызовов функций и выражений присваивания. Для составных инструкций с фигурными скобками (`if`, `while`, `for`, `func`) закрывающая фигурная скобка `}` завершает блок, и дополнительная точка с запятой не требуется.

## 2. Зарезервированные ключевые слова

Ниже приведён полный список ключевых слов, распознаваемых лексическим анализатором N&S:

| Ключевое слово | Описание | Пример использования |
| :--- | :--- | :--- |
| `let` | Объявление новой переменной в текущей области видимости | `let x = 10;` |

| `false` | Литерал логической лжи | `let finished = false;` |

| `print` | Инструкция вывода (альтернатива встроенной функции) | `print "Текст";` |

## 3. Система типов данных

N&S использует динамическую типизацию с проверкой типов во время выполнения (Runtime Type System). В рантайме представлены следующие типы данных:

| Тип | Обозначение в рантайме | Описание | Пример |
| :--- | :--- | :--- | :--- |
| **Null** | `null` | Отсутствие значения | `let a = null;` |
| **Bool** | `bool` | Логический тип (`true` или `false`) | `let flag = true;` |
| **Int** | `int` | 64-битное знаковое целое число (`i64`) | `let count = 42;` |
| **Float** | `float` | 64-битное число с плавающей точкой (`f64`) | `let pi = 3.14159;` |
| **String** | `string` | Строка символов UTF-8 | `let text = "N&S";` |
| **Array** | `array` | Динамический изменяемый массив элементов | `let list = [1, "два", 3.0];` |
| **Map** | `map` | Ассоциативный массив (словарь) ключ-значение | `let obj = {"x": 10, "y": 20};` |
| **Function** | `function` | Пользовательская функция с замыканием | `let f = func(x) { return x * 2; };` |
| **NativeFunction** | `native_function` | Встроенная функция на языке Rust | `print`, `web.get` |

### 3.1. Логическая истинность (Truthy / Falsy)
Любое значение может быть вычислено в булевом контексте (`if`, `while`, операторы `&&`, `||`, `!`):
* **Falsy (ложные значения):** `null`, `false`, `0`, `0.0`, пустая строка `""`, пустой массив `[]`, пустой словарь `{}`.
* **Truthy (истинные значения):** любые ненулевые числа, непустые строки, непустые массивы и словари, все функции.

### 3.2. Массивы (Array)
Массивы создаются с помощью квадратных скобок `[` и `]`:
```javascript
let arr = [10, 20, 30, 40];
```
* **Индексация:** начинается с нуля: `arr[0]` вернёт `10`.
* **Отрицательные индексы:** поддерживается доступ с конца массива: `arr[-1]` вернёт `40`, `arr[-2]` вернёт `30`.
* **Выход за границы:** обращение по индексу вне границ массива возвращает `null` без паники.
* **Мутация по ссылке:** массивы хранятся по ссылке (`Rc<RefCell<Vec<Value>>>`). Изменение массива через одну переменную отражается во всех ссылках на него.
* **Свойства и методы массивов:**
  * `arr.length` — длина массива (целое число `Int`).
  * `arr.push(item)` — добавляет элемент в конец массива.
  * `arr.pop()` — удаляет последний элемент из массива и возвращает его (или `null`, если массив пуст).

```javascript
let items = ["A", "B"];
items.push("C");
print(items.length); // 3
let last = items.pop();
print(last);         // C
```

### 3.3. Словари и ассоциативные карты (Map)
Словари создаются с помощью фигурных скобок `{` и `}` с парами `"ключ": значение`:
```javascript
let person = {
    "name": "Иван",
    "age": 28,
    "skills": ["Rust", "N&S"]
};
```
* **Доступ к полям:** поддерживается через точку `person.name` или через строковый индекс `person["name"]`.
* **Присваивание:** `person.age = 29;` или `person["city"] = "Москва";`.
* **Несуществующий ключ:** возвращает `null`.
* **Мутация по ссылке:** словари хранятся как `Rc<RefCell<IndexMap<String, Value>>>`.

### 3.4. Строки (String)
Строки в N&S неизменяемы, поддерживают конкатенацию оператором `+` и повторение оператором `*`:
* `str.length` — количество символов в строке.
* `str.upper()` — возвращает новую строку в верхнем регистре.
* `str.lower()` — возвращает новую строку в нижнем регистре.
* `str.trim()` — возвращает строку с удалёнными пробелами по краям.

```javascript
let s = "  hello world  ";
print(s.trim().upper()); // HELLO WORLD
```

## 4. Таблица операторов и приоритеты

Операторы перечислены в порядке убывания приоритета (от наивысшего к наинизшему):

| Приоритет | Операторы | Тип | Ассоциативность | Описание и поведение типов |
| :---: | :---: | :---: | :---: | :--- |
| **1 (Высший)** | `.` `[]` `()` | Постфиксные | Слева направо | Доступ к свойствам, индексация, вызов функций |
| **2** | `-` `!` | Префиксные (унарные) | Справа налево | Унарный минус (числа), логическое отрицание |
| **3** | `*` `/` `%` | Мультипликативные | Слева направо | Умножение (`Int*Int`, `Float*Float`, `String*Int`), деление (с защитой от деления на 0), остаток от деления |
| **4** | `+` `-` | Аддитивные | Слева направо | Сложение чисел, конкатенация строк `String + Any`, слияние массивов `Array + Array`, вычитание чисел |
| **5** | `<` `<=` `>` `>=` | Сравнения | Слева направо | Сравнение чисел (`Int`, `Float`) и лексикографическое сравнение строк |
| **6** | `==` `!=` | Равенство | Слева направо | Проверка равенства (поддерживает числа с автоприведением `Int == Float`, строки, массивы, словари) |
| **7** | `&&` | Логическое И | Слева направо | Короткое замыкание (Short-circuit evaluation) |
| **8** | `\|\|` | Логическое ИЛИ | Слева направо | Короткое замыкание |
| **9 (Низший)** | `=` `+=` `-=` `*=` `/=` | Присваивание | Справа налево | Присваивание в переменную, поле словаря или элемент массива |

### Особенности поведения операторов:
* **Деление на ноль:** если делитель равен `0` или `0.0`, рантайм выбрасывает читаемую ошибку `[Runtime Error] Division by zero` с кодом выхода 1 без паники процесса.
* **Строковое сложение:** если один из операндов оператора `+` является строкой, второй операнд автоматически приводится к строковому представлению.
* **Повторение строк:** выражение `"abc" * 3` или `3 * "abc"` даёт `"abcabcabc"`. Отрицательный множитель даёт пустую строку `""`.
* **Слияние массивов:** `[1, 2] + [3, 4]` создаёт новый массив `[1, 2, 3, 4]`.

## 5. Управляющие конструкции

### 5.1. Условный оператор `if` / `else`
```javascript
let score = 85;

if (score >= 90) {
    print("Отлично");
} else if (score >= 70) {
    print("Хорошо");
} else {
    print("Удовлетворительно");
}
```

### 5.2. Цикл `while`
Цикл `while` выполняется до тех пор, пока условие истинно:
```javascript
let i = 0;
let total = 0;

while (i < 5) {
    total += i;
    i += 1;
}
print("Сумма: " + total); // Сумма: 10
```

### 5.3. Цикл `for..in`
Цикл `for..in` последовательно перебирает элементы массива:
```javascript
let fruits = ["яблоко", "банан", "груша"];

for fruit in fruits {
    print("Фрукт: " + fruit);
}
```

## 6. Функции, рекурсия и области видимости

### 6.1. Объявление и вызов функций
Функции объявляются ключевым словом `func`:
```javascript
func multiply(a, b) {
    return a * b;
}

let res = multiply(6, 7);
print(res); // 42
```
* Если функция не содержит явного вызова `return`, она возвращает `null`.
* **Проверка арности:** при передаче неверного числа аргументов генерируется ошибка:
  `[Runtime Error] Function 'multiply' expects 2 arguments, but 1 were provided`.

### 6.2. Анонимные функции (лямбды)
Функции являются объектами первого класса (First-Class Citizens) и могут быть присвоены переменным или переданы как аргументы:
```javascript
let square = func(n) {
    return n * n;
};

print(square(5)); // 25
```

### 6.3. Рекурсия
Функции могут вызывать сами себя. Локальные переменные изолируются в каждом фрейме вызова:
```javascript
func factorial(n) {
    if (n <= 1) {
        return 1;
    }
    return n * factorial(n - 1);
}

print(factorial(6)); // 720
```

### 6.4. Области видимости (Environment)
* Переменные, объявленные через `let`, имеют блочную область видимости (Block Scope).
* Вложенные блоки `{ ... }` создают дочернюю область видимости, имеющую доступ к переменным родительских блоков.
* Объявление переменной с тем же именем во внутреннем блоке скрывает (shadows) внешнюю переменную, не перезаписывая её.

```javascript
let x = 100;

{
    let x = 42; // Локальная переменная блока
    print(x);   // 42
}

print(x);       // 100 (внешняя переменная не изменилась)
```
