# Стандартная библиотека: Ядро (`io`, `math`, `cli`)

В данном документе приведено исчерпывающее описание всех встроенных глобальных функций интерпретатора N&S, а также модулей стандартной библиотеки `io`, `math` и `cli`.

---

## 1. Глобальные встроенные функции

Глобальные функции доступны в любой части программы без необходимости вызова инструкции `import`.

### 1.1. `print`
- **Сигнатура:** `print(arg1: Any, arg2: Any, ...) -> Null`
- **Описание:** Выводит строковые представления переданных аргументов в стандартный поток вывода (`stdout`), разделяя их одним пробелом, и завершает вывод символом новой строки `\n`. Автоматически форматирует массивы, словари, примитивные типы и функции.
- **Пример:**
  ```javascript
  let user = "Алексей";
  let age = 25;
  print("Пользователь:", user, "Возраст:", age);
  ```
- **Результат:**
  ```text
  Пользователь: Алексей Возраст: 25
  ```

---

### 1.2. `input`
- **Сигнатура:** `input(prompt?: String) -> Int | Float | Bool | String`
- **Описание:** Если передан строковый аргумент `prompt`, выводит его в консоль без переноса строки и сбрасывает буфер вывода. Затем считывает строку из стандартного ввода (`stdin`) и выполняет интеллектуальное автоматическое приведение типов:
  1. Если строка парсится как целое число, возвращает `Int`.
  2. Если парсится как вещественное число, возвращает `Float`.
  3. Если равна `"true"` (регистронезависимо), возвращает `Bool(true)`.
  4. Если равна `"false"` (регистронезависимо), возвращает `Bool(false)`.
  5. В остальных случаях возвращает очищенную от пробелов строку `String`.
- **Пример:**
  ```javascript
  let age = input("Введите ваш возраст: ");
  print("Через год вам будет:", age + 1);
  ```

---

### 1.3. `random`
- **Сигнатура:** `random(min?: Number, max?: Number) -> Int | Float`
- **Описание:**
  * Если вызвана без аргументов: генерирует псевдослучайное вещественное число (`Float`) в полуинтервале `[0.0, 1.0)`.
  * Если передан 1 аргумент `max`: генерирует случайное целое число (`Int`) в диапазоне от `0` до `max` включительно.
  * Если переданы 2 аргумента `min` и `max`: генерирует случайное целое число (`Int`) в диапазоне от `min` до `max` включительно (даже если `min > max`, диапазон нормализуется автоматически).
- **Пример:**
  ```javascript
  let dice = random(1, 6);
  print("Бросок кубика:", dice);
  ```

---

### 1.4. `browse`
- **Сигнатура:** `browse(url: String) -> Null`
- **Описание:** Открывает переданный URL-адрес или локальный файл в веб-браузере операционной системы по умолчанию. Использует нативные команды платформы: `cmd /C start` на Windows, `xdg-open` на Linux, `open` на macOS.
- **Пример:**
  ```javascript
  browse("http://localhost:8080");
  ```

---

### 1.5. `len`
- **Сигнатура:** `len(value: String | Array | Map) -> Int`
- **Описание:** Возвращает размер коллекции или длину строки в символах:
  * Для `String`: количество символов UTF-8.
  * Для `Array`: количество элементов в массиве.
  * Для `Map`: количество пар ключ-значение в словаре.
  * Если передан неподдерживаемый тип, выбрасывает `[Runtime Error] Type '...' has no length`.
- **Пример:**
  ```javascript
  print(len("Привет"));        // 6
  print(len([10, 20, 30]));    // 3
  print(len({"a": 1, "b": 2})); // 2
  ```

---

### 1.6. `exit`
- **Сигнатура:** `exit(code?: Int) -> Never`
- **Описание:** Немедленно завершает процесс выполнения программы с указанным целочисленным кодом выхода (по умолчанию `0`).
- **Пример:**
  ```javascript
  if (error_occurred) {
      print("[Error] Критическая ошибка");
      exit(1);
  }
  ```

---

### 1.7. Функции презентаций (Presentation Builtins)
В ядре интерпретатора зарегистрированы функции декларативной разметки презентаций: `title`, `header`, `paragraph`, `joystick_card`, `presentation_start`, `slide`, `presentation_end`, `button`, `downloadTemplate`.
- **Сигнатура:** `fn(arg1?: Any, ...) -> Null`
- **Описание:** Принимают произвольное количество аргументов, форматируют их через дефис и выводят структурированный лог с префиксом `[Presentation]`.
- **Пример:**
  ```javascript
  title("Архитектура N&S");
  slide("Слайд 1", "Введение в язык");
  ```
- **Результат:**
  ```text
  [Presentation] Архитектура N&S
  [Presentation] Слайд 1 - Введение в язык
  ```

## 2. Модуль `io` (Ввод-вывод и файловая система)

Импортируется инструкцией:
```javascript
import "io" as io
```

### 2.1. `io.read_file`
- **Сигнатура:** `io.read_file(path: String) -> String`
- **Описание:** Считывает всё содержимое файла по указанному пути в кодировке UTF-8 и возвращает его в виде строки. При ошибке доступа или отсутствии файла выбрасывает `[Runtime Error] Failed to read file '...': ...`.
- **Пример:**
  ```javascript
  let config = io.read_file("config.json");
  print(config);
  ```

### 2.2. `io.write_file`
- **Сигнатура:** `io.write_file(path: String, content: String) -> Bool`
- **Описание:** Создаёт новый файл или перезаписывает существующий, записывая в него переданный контент. При успешной записи возвращает `true`.
- **Пример:**
  ```javascript
  io.write_file("output.txt", "Данные расчета: 42");
  ```

### 2.3. `io.exists`
- **Сигнатура:** `io.exists(path: String) -> Bool`
- **Описание:** Проверяет физическое существование файла или каталога по указанному пути. Возвращает `true`, если объект существует, и `false` в противном случае.
- **Пример:**
  ```javascript
  if (io.exists("data.txt")) {
      print("Файл найден");
  }
  ```

### 2.4. `io.delete_file` / `io.remove_file`
- **Сигнатура:** `io.delete_file(path: String) -> Bool`
- **Описание:** Удаляет указанный файл с диска. Метод `io.remove_file` является полным алиасом `io.delete_file`. При успешном удалении возвращает `true`. Если файл не найден или занят другим процессом, выбрасывает читаемую ошибку.
- **Пример:**
  ```javascript
  io.delete_file("temp.txt");
  ```

### 2.5. `io.print` и `io.input`
- **Сигнатура:** `io.print(...) -> Null`, `io.input(prompt?: String) -> Any`
- **Описание:** Модульные зеркала глобальных функций `print` и `input` для библиотечного стиля оформления кода.

### 2.6. `io.browse`
- **Сигнатура:** `io.browse(url: String) -> Null`
- **Описание:** Модульный алиас глобальной функции `browse`.

## 3. Модуль `math` (Математика и случайные числа)

Импортируется инструкцией:
```javascript
import "math" as math
```

### 3.1. Константы
* `math.PI` (`Float`) — число Пи: `3.141592653589793`.
* `math.E` (`Float`) — основание натурального логарифма (число Эйлера): `2.718281828459045`.

### 3.2. `math.sqrt`
- **Сигнатура:** `math.sqrt(x: Number) -> Float`
- **Описание:** Вычисляет квадратный корень числа `x`.
- **Пример:**
  ```javascript
  print(math.sqrt(144)); // 12.0
  ```

### 3.3. `math.pow`
- **Сигнатура:** `math.pow(base: Number, exp: Number) -> Float`
- **Описание:** Возводит число `base` в степень `exp`.
- **Пример:**
  ```javascript
  print(math.pow(2, 10)); // 1024.0
  ```

### 3.4. `math.abs`
- **Сигнатура:** `math.abs(x: Number) -> Number`
- **Описание:** Возвращает абсолютное значение числа, сохраняя его исходный тип (`Int` для целых, `Float` для вещественных).
- **Пример:**
  ```javascript
  print(math.abs(-42));   // 42
  print(math.abs(-3.14)); // 3.14
  ```

### 3.5. Тригонометрия: `math.sin`, `math.cos`, `math.tan`
- **Сигнатура:**
  * `math.sin(rad: Number) -> Float`
  * `math.cos(rad: Number) -> Float`
  * `math.tan(rad: Number) -> Float`
- **Описание:** Вычисляют синус, косинус и тангенс угла, заданного в радианах.
- **Пример:**
  ```javascript
  let angle = math.PI / 2.0;
  print(math.sin(angle)); // 1.0
  ```

### 3.6. Округление: `math.floor`, `math.ceil`, `math.round`
- **Сигнатура:**
  * `math.floor(x: Number) -> Int` — округление вниз до ближайшего целого.
  * `math.ceil(x: Number) -> Int` — округление вверх до ближайшего целого.
  * `math.round(x: Number) -> Int` — математическое округление до ближайшего целого.
- **Пример:**
  ```javascript
  print(math.floor(3.9)); // 3
  print(math.ceil(3.1));  // 4
  print(math.round(3.5)); // 4
  ```

### 3.7. `math.random`
- **Сигнатура:** `math.random(min?: Number, max?: Number) -> Number`
- **Описание:** Модульный алиас генератора случайных чисел, аналогичный глобальному `random`.

## 4. Модуль `cli` (Управление консолью и цветами)

Импортируется инструкцией:
```javascript
import "cli" as cli
```

### 4.1. `cli.args`
- **Сигнатура:** `cli.args() -> Array<String>`
- **Описание:** Возвращает массив аргументов командной строки, переданных скрипту при запуске (без учёта флагов интерпретатора).
- **Пример:**
  Запуск: `ns script.ns -- --port 8080 --debug`
  ```javascript
  let args = cli.args();
  print("Получено аргументов:", len(args));
  for arg in args {
      print("->", arg);
  }
  ```

### 4.2. ANSI-цвета и стилизация
Функции стилизации оборачивают строку в соответствующие управляющие последовательности ANSI и сбрасывают цвет в конце строки (`\x1b[0m`):

* `cli.green(text: String) -> String` — зелёный цвет (`\x1b[32m`)
* `cli.red(text: String) -> String` — красный цвет (`\x1b[31m`)
* `cli.blue(text: String) -> String` — синий цвет (`\x1b[34m`)
* `cli.yellow(text: String) -> String` — жёлтый цвет (`\x1b[33m`)
* `cli.cyan(text: String) -> String` — голубой/циан цвет (`\x1b[36m`)
* `cli.magenta(text: String) -> String` — пурпурный цвет (`\x1b[35m`)
* `cli.bold(text: String) -> String` — полужирный текст (`\x1b[1m`)

Пример:
```javascript
print(cli.green("[OK] Тест пройден успешно"));
print(cli.red("[Error] Ошибка подключения к базе данных"));
print(cli.bold(cli.cyan("Заголовок отчёта")));
```

### 4.3. `cli.clear`
- **Сигнатура:** `cli.clear() -> Null`
- **Описание:** Очищает экран терминала. На платформе Windows вызывает системную утилиту `cmd /c cls`, на Unix-системах выводит управляющую последовательность `\x1b[2J\x1b[1;1H`.
- **Пример:**
  ```javascript
  cli.clear();
  print("Консоль очищена.");
  ```
