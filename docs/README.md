# Документация языка N&S (Nova Script)

Добро пожаловать в официальную техническую документацию языка программирования **N&S (Nova Script)**.

N&S — это высокопроизводительный, динамически типизированный язык программирования общего назначения, полностью написанный на языке **Rust**. Язык сочетает простоту и читаемость синтаксиса в стиле JavaScript/Python с высокой скоростью выполнения, типобезопасным рантаймом, встроенным веб-сервером, 2D-движком на базе HTML5 Canvas и прямой интеграцией с системным языком GrassGreen.

---

## Ключевые особенности

* **Ядро на Rust:** Интерпретатор, лексер, рекурсивный нисходящий парсер и AST-рантайм разработаны на Rust с нулевыми накладными расходами и абсолютной защитой памяти.
* **Автономный инструмент:** Единый исполняемый файл `ns.exe` объединяет интерпретатор скриптов, интерактивную консоль REPL, Language Server (LSP) и автоматический установщик расширения для VS Code.
* **Встроенный Web-стек:** Модуль `web` позволяет поднимать HTTP-серверы, настраивать маршрутизацию `GET`/`POST`, обрабатывать JSON и генерировать фронтенд без внешних зависимостей.
* **2D-графика в браузере:** Модуль `game2d` разворачивает локальный холст HTML5 Canvas с частотой 60 FPS, примитивами, спрайтами и считыванием событий клавиатуры и мыши без необходимости сборки тяжёлых нативных графических библиотек.
* **FFI с GrassGreen:** Прямой вызов функций из файлов `.grass` и выполнение встроенных блоков `extern "grass"` с обменом данными и типами.
* **Обратная совместимость:** Полная поддержка как современных файлов `.ns`, так и скриптов классического прототипа `.nova`.

## Установка и быстрый старт

### Способ 1. Готовый графический установщик Windows
Для операционных систем Windows подготовлен классический мастер установки:
1. Запустите файл `installer/setup.exe`.
2. Мастер установки скопирует бинарные файлы, автоматически добавит `ns.exe` в системную переменную `PATH`, зарегистрирует расширения `.ns` и `.nova` в Проводнике Windows с фирменной иконкой и предложит настроить расширение для VS Code.

### Способ 2. Сборка из исходников
Для сборки требуется компилятор Rust (версии 1.75 или новее) и Cargo:

```bash
git clone https://github.com/m1oky/NovaScript.git
cd NovaScript

# Сборка оптимизированного бинарника
cargo build --release

# Регистрация ассоциаций файлов и иконки в Windows Explorer
./target/release/ns register

# Установка расширения подсветки и автодополнения в VS Code
./target/release/ns setup-vscode
```

## Первая программа: Hello, World

Создайте файл `hello.ns`:

```javascript
// hello.ns
import "cli" as cli

let name = "N&S";
print("Hello, World from " + name + "!");

// Демонстрация форматирования терминала
print(cli.green("[OK] Программа успешно выполнена."));
```

Запустите программу через терминал:

```bash
ns hello.ns
```

Вывод программы:
```text
Hello, World from N&S!
[OK] Программа успешно выполнена.
```
