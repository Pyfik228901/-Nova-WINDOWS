# Стандартная библиотека: Web (`web`)

Модуль `web` предоставляет полноценный стек для создания веб-приложений на языке **N&S**: встроенный легковесный HTTP-сервер на базе Rust-крейта `tiny_http`, роутер запросов `GET` и `POST`, инструменты сериализации JSON и генератор фронтенд-страниц.

Импортируется инструкцией:
```javascript
import "web" as web
```

---

## 1. Архитектура работы HTTP-сервера

Встроенный веб-сервер привязывается к указанному порту на всех локальных интерфейсах (`0.0.0.0:<port>`) и обрабатывает входящие HTTP-запросы в цикле.
* Сервер работает синхронно на уровне цикла обработки запросов, вызывая зарегистрированные функции-обработчики (Handler) в изолированном контексте интерпретатора.
* **Объект запроса (`req`):** Обработчик маршрута принимает один аргумент — ассоциативную карту `Map`, содержащую поля:
  * `req.method` (`String`) — HTTP-метод в верхнем регистре (`"GET"`, `"POST"`).
  * `req.path` (`String`) — путь URL без параметров строки запроса (например, `"/api/users"`).
  * `req.body` (`String`) — необработанное тело запроса в виде строки.
* **Автоматическое определение типа контента (`Content-Type`):** Тип ответа определяется по возвращаемому значению функции-обработчика:
  * Строка, начинающаяся с символа `<` — отдаётся как `text/html; charset=utf-8`.
  * Строка, начинающаяся с `{` или `[` — отдаётся как `application/json; charset=utf-8`.
  * Любая другая строка — отдаётся как `text/plain; charset=utf-8`.
  * Объект `Map` или массив `Array` — автоматически сериализуется в JSON и отдаётся с заголовком `application/json; charset=utf-8`.
  * Другие типы — преобразуются в строку и отдаются как `text/plain`.

## 2. Функции маршрутизации и сервера

### 2.1. `web.get`
- **Сигнатура:** `web.get(path: String, handler: Function) -> Null`
- **Описание:** Регистрирует функцию-обработчик для HTTP-метода `GET` по указанному пути `path`.
- **Пример:**
  ```javascript
  web.get("/", func(req) {
      return web.html("Главная страница", web.tag("h1", {}, "Добро пожаловать в N&S Web!"));
  });
  ```

---

### 2.2. `web.post`
- **Сигнатура:** `web.post(path: String, handler: Function) -> Null`
- **Описание:** Регистрирует функцию-обработчик для HTTP-метода `POST`. Позволяет считывать тело запроса через `req.body`, парсить входящий JSON с помощью `web.json_parse` и возвращать результат.
- **Пример:**
  ```javascript
  web.post("/api/echo", func(req) {
      let data = web.json_parse(req.body);
      return {
          "status": "success",
          "received": data
      };
  });
  ```

---

### 2.3. `web.server` / `web.listen`
- **Сигнатура:** `web.server(port: Int) -> Null`
- **Описание:** Запускает прослушивание входящих подключений на указанном порту. Метод `web.listen` является полным синонимом `web.server`. После старта сервер выводит информационное сообщение в консоль:
  ```text
  [OK] N&S Web Server running on http://localhost:8080
  [Info] Press Ctrl+C to stop server.
  ```
  Вызов блокирует дальнейшее выполнение текущего скрипта до остановки сервера.
- **Пример:**
  ```javascript
  web.server(8080);
  ```

---

### 2.4. Остановка сервера (Graceful Shutdown)
Сервер поддерживает два механизма остановки:
1. **Сигнал прерывания:** нажатие сочетания клавиш `Ctrl + C` в терминале.
2. **Программная остановка через маршрут:**
   * Отправка запроса на маршрут `GET /shutdown` автоматически закрывает сокет сервера и завершает цикл обработки.
   * Либо любой обработчик может вернуть карту со специальным флагом: `return { "shutdown": true };`. Сервер отправит клиенту ответ и затем корректно завершит работу, позволив скрипту продолжить выполнение.

Пример:
```javascript
web.get("/stop", func(req) {
    return {
        "status": "server stopped",
        "shutdown": true
    };
});
```

## 3. Работа с JSON

### 3.1. `web.json_stringify`
- **Сигнатура:** `web.json_stringify(value: Any) -> String`
- **Описание:** Преобразует структуры данных N&S (`Map`, `Array`, `String`, `Int`, `Float`, `Bool`, `Null`) в форматированную читаемую строку JSON с отступами.
- **Пример:**
  ```javascript
  let user = {
      "id": 1,
      "username": "admin",
      "roles": ["read", "write"]
  };

  let json_text = web.json_stringify(user);
  print(json_text);
  ```
- **Результат:**
  ```json
  {
    "id": 1,
    "roles": [
      "read",
      "write"
    ],
    "username": "admin"
  }
  ```

---

### 3.2. `web.json_parse`
- **Сигнатура:** `web.json_parse(json_str: String) -> Any`
- **Описание:** Парсит строку JSON и возвращает соответствующие нативные структуры данных N&S. Объекты JSON превращаются в `Map`, списки — в `Array`, примитивы — в соответствующие типы. При некорректном формате JSON выбрасывает ошибку с описанием синтаксической проблемы.
- **Пример:**
  ```javascript
  let raw = '{"status": 200, "message": "OK"}';
  let parsed = web.json_parse(raw);

  print(parsed.status);  // 200
  print(parsed.message); // OK
  ```

## 4. Генерация фронтенда и HTML-страниц

### 4.1. `web.html`
- **Сигнатура:** `web.html(title: String, body: String) -> String`
- **Описание:** Генерирует валидный адаптивный HTML5-документ с современной тёмной темой оформления (CSS-переменные, сглаживание шрифтов, стилизованный центрированный контейнер, акцентные цвета и кнопки).
- **Пример:**
  ```javascript
  let page = web.html("Панель управления", "<h2>Добро пожаловать</h2><p>Система готова к работе.</p>");
  ```

---

### 4.2. `web.tag`
- **Сигнатура:** `web.tag(name: String, attrs?: Map, content?: String) -> String`
- **Описание:** Вспомогательная функция для генерации валидных HTML-тегов с атрибутами и вложенным содержимым.
  * `name`: имя тега (`"h1"`, `"div"`, `"button"`, `"a"` и т.д.).
  * `attrs`: словарь атрибутов тега (например, `{"class": "btn", "id": "submit-btn"}`).
  * `content`: вложенный HTML или текст.
- **Пример:**
  ```javascript
  let link = web.tag("a", {"href": "/docs", "target": "_blank"}, "Читать документацию");
  print(link);
  // <a href="/docs" target="_blank">Читать документацию</a>
  ```

## 5. Полный пример: REST API и веб-сайт

```javascript
// server.ns
import "web" as web

// 1. Главная страница сайта
web.get("/", func(req) {
    let header = web.tag("h1", {}, "N&S Micro-Framework");
    let desc = web.tag("p", {}, "Простой и быстрый веб-сервер на Rust.");
    let button = web.tag("button", {"class": "btn"}, "Кликни меня");

    return web.html("Главная", header + desc + button);
});

// 2. REST API: Получение списка задач
let todos = ["Изучить N&S", "Написать 2D игру", "Собрать проект"];

web.get("/api/todos", func(req) {
    return {
        "status": "success",
        "count": len(todos),
        "items": todos
    };
});

// 3. Маршрут остановки
web.get("/stop", func(req) {
    return {
        "status": "stopping",
        "shutdown": true
    };
});

// Запуск сервера на порту 8080
print("[Info] Запуск сервера...");
web.server(8080);
```
