# CLI и инструменты разработчика

Бинарный файл `ns` (`ns.exe` на платформе Windows) является единым центром управления разработкой на языке **N&S (Nova Script)**. Он включает в себя интерпретатор скриптов, интерактивную консоль REPL, генератор шаблонов проектов, систему регистрации ассоциаций операционной системы, Language Server Protocol (LSP) сервер и установщик расширения для VS Code.

---

## 1. Команды и флаги командной строки `ns`

Базовый синтаксис вызова утилиты:
```bash
ns [ОПЦИИ] [КОМАНДА] [АРГУМЕНТЫ...]
```

### 1.1. Таблица всех команд

| Команда | Описание | Пример вызова |
| :--- | :--- | :--- |
| *(без аргументов)* | Запуск интерактивной консоли REPL | `ns` |
| `<файл.ns>` | Прямой запуск скрипта | `ns main.ns` |
| `run <файл>` | Явный запуск файла скрипта с передачей аргументов | `ns run main.ns --port 8080` |
| `repl` | Явный запуск интерактивной консоли REPL | `ns repl` |
| `init <имя>` | Создание шаблона нового проекта | `ns init my_project` |
| `register` | Регистрация расширений `.ns`/`.nova` и иконки в Windows Explorer | `ns register` |
| `setup-vscode` | Автоматическая установка расширения для Visual Studio Code | `ns setup-vscode` |
| `lsp` | Запуск сервера Language Server Protocol по stdio | `ns lsp` |

### 1.2. Флаг `--eval` (`-e`)
Позволяет выполнить фрагмент кода на языке N&S напрямую из терминала без создания отдельного файла:
- **Синтаксис:** `ns -e "<code>"` или `ns --eval "<code>"`
- **Пример:**
  ```bash
  ns -e "let a = 15; let b = 27; print('Сумма:', a + b);"
  ```
- **Результат:**
  ```text
  Сумма: 42
  ```

### 1.3. Передача аргументов в скрипт
Любые аргументы, переданные после имени файла скрипта (или после разделителя `--`), доступны внутри скрипта через функцию `cli.args()` модуля `"cli"`:
```bash
ns app.ns arg1 arg2 --mode production
```
Внутри `app.ns`:
```javascript
import "cli" as cli

let args = cli.args();
// args содержит: ["arg1", "arg2", "--mode", "production"]
```

### 1.4. Команда `ns init <name>`
Создаёт директорию с шаблоном нового проекта:
```bash
ns init game_project
```
Структура создаваемого проекта:
```text
game_project/
├── .gitignore
├── README.md
└── src/
    └── main.ns
```
Файл `src/main.ns` содержит стартовый шаблон с импортами `cli` и базовой функцией `main()`.

### 1.5. Команда `ns register`
Регистрирует ассоциации файлов `.ns` и `.nova` в реестре текущего пользователя Windows (`HKCU\Software\Classes`):
* Привязывает ProgID `NS.Script`.
* Устанавливает фирменную векторную иконку из `assets/icon.ico`.
* Назначает команду открытия по умолчанию через `ns.exe "%1"`.
* Отправляет системное уведомление оболочке `SHChangeNotify(SHCNE_ASSOCCHANGED)`, благодаря чему Проводник Windows сразу отображает логотип N&S на всех файлах скриптов.

## 2. Интерактивная консоль (REPL)

Консоль REPL (Read-Eval-Print Loop) предназначена для быстрого экспериментирования, прототипирования функций и тестирования математических выражений.

Запуск консоли:
```bash
ns
```
или
```bash
ns repl
```

### 2.1. Особенности REPL
* **Многострочный ввод:** интерпретатор анализирует баланс открывающих и закрывающих фигурных скобок `{}` и круглых скобок `()`. Если блок остался незавершённым, приглашение к вводу меняется на `... `, позволяя вводить функции и циклы целиком.
* **История команд:** введённые команды сохраняются в домашней директории пользователя в файле `~/.ns_history` и доступны для перелистывания стрелками Вверх/Вниз.
* **Автовычисление выражений:** если введённая строка является выражением (а не инструкцией `let`), REPL автоматически печатает результат вычисления.

### 2.2. Служебные команды REPL
* `exit` или `quit` — завершить сессию REPL и выйти в терминал.
* `clear` — очистить экран терминала.

Пример сессии в REPL:
```text
=== N&S (Nova Script) v1.0.0 Interactive REPL ===
Type 'exit' to quit, 'clear' to clear screen.

ns> let a = 10;
ns> func add(x) {
...     return x + a;
... }
ns> add(5)
15
ns> exit
```

## 3. Language Server Protocol (LSP)

Команда `ns lsp` запускает встроенный Language Server, реализующий стандарт JSON-RPC 2.0 поверх стандартных потоков ввода/вывода (`stdin` / `stdout`).

### 3.1. Поддерживаемые возможности протокола
* **`initialize`:** возвращает информацию о сервере (`ns-lsp v1.0.0`) и параметры синхронизации документов (`textDocumentSync: Full`).
* **`textDocument/didOpen` и `textDocument/didChange`:** выполняет синтаксический анализ кода на лету и отправляет диагностику (`publishDiagnostics`) с указанием точных строк и колонок синтаксических ошибок.
* **`textDocument/completion`:** отдаёт контекстный список автодополнения для ключевых слов, стандартных модулей и встроенных функций при вводе символов `.`, `(`, пробела или кавычек.
* **`shutdown` и `exit`:** корректно завершают процесс сервера.

Формат сообщений соответствует стандарту LSP с заголовком длины:
```text
Content-Length: ...\r\n\r\n{"jsonrpc":"2.0", ...}
```

## 4. Расширение для Visual Studio Code

N&S поставляется с готовым расширением для редактора Visual Studio Code, которое устанавливается локально одной командой без необходимости публикации в Marketplace.

### 4.1. Установка расширения
Выполните команду в терминале:
```bash
ns setup-vscode
```

Команда автоматически разворачивает расширение в системный каталог:
`%USERPROFILE%\.vscode\extensions\m1oky.ns-lang-support-1.0.0`

### 4.2. Содержимое расширения
* **Синтаксическая подсветка TextMate (`syntaxes/ns.tmLanguage.json`):**
  * Комментарии: однострочные `//` и многострочные `/* */`.
  * Строки с экранированием.
  * Числа (целые и с плавающей точкой).
  * Ключевые слова управления (`if`, `else`, `while`, `for`, `in`, `return`).
  * Ключевые слова объявлений (`let`, `func`, `import`, `as`, `extern`).
  * Модули (`web`, `game2d`, `cli`, `math`, `io`).
  * Встроенные функции и операторы.
* **Умное автодополнение и подсказки (`extension.js`):**
  * Контекстные подсказки методов при вводе через точку (например, `web.`, `game2d.`, `math.`, `io.`, `cli.`).
  * Подсказки всех ключевых слов и встроенных функций.
  * Всплывающие подсказки документации при наведении курсора (Hover).
* **Сниппеты кода (`snippets/snippets.json`):**
  * Быстрая вставка шаблонов функций (`func`), циклов (`for`, `while`), импортов и блоков `extern "grass"`.
* **Иконка файлов в проводнике VS Code:**
  * Собственная тема иконок `icons/ns-icon-theme.json` с векторным логотипом [assets/logo.svg](file:///c:/Users/m1oky/Desktop/NovaScript/assets/logo.svg), отображающаяся напротив каждого файла `.ns` и `.nova`.
* **Запуск по горячей клавише `F5`:**
  * Команда `N&S: Запустить текущий скрипт [F5]` запускает скрипт в интегрированном терминале редактора.
  * Кнопка запуска в Status Bar редактора: `$(play) N&S: Запустить (F5)`.
